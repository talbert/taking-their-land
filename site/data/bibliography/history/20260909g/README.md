website separately reports issue publication in 2019 and article publication
in 2022. These dates retain their distinct roles. Breasted's 1906 publication

Metadata identity does not establish a source's support for a historical
claim. Source passages, editions and generic topic labels still require
research. No historical claim, event date, statistical input or evidence hold
is changed by this metadata update. Copyrighted source bodies and private
captures are excluded from this bibliography bundle.
